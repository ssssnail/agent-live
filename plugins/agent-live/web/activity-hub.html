LAYOUT IDEA 01

Tech Studio · Activity-Based

先让家具和空间像真实科技工作室，再让 Agent 根据工作语义选择区域。无需阅读标签，也应该知道每个人在做什么。

工作映射

Focus Bench编码 / 写作 / 深度思考
Research Wall搜索 / 阅读 / 分析
Project Room计划 / 协作 / 评审
Build Lab运行 / 测试 / 调试
Phone Booth网络 / 提问 / 外部服务
Pantry Lounge接水 / 休息 / 非正式交流

与当前 Demo 的差异

  • 保留真实科技办公室的开放工作台，但不绑定员工。
  • 项目室和电话亭使用玻璃隔断，不遮挡全场视线。
  • Build Lab 有测试台、设备架和状态屏，而不是抽象色块。
  • Pantry 有冰箱、水机、咖啡机、吧台和沙发。
