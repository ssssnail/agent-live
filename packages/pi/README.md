# Agent Live for Pi

Pi adapter for [Agent Live](https://github.com/ssssnail/agent-live). It includes the lightweight local office runtime and opens no cloud service.

```bash
pi install npm:@iniesta8888/agent-live-pi
```

Restart Pi and run `/agent-live`. Use `/agent-live custom` to customize the selected office and `/agent-live exit` to leave Creator Mode. `/agent-live reset` explains the local-data reset; `/agent-live reset confirm` performs it and restores the built-in `tech` office.
