01 / WHY

状态不应该只存在于日志里。

Agent Office 不是给 Agent 加一个宠物，而是给它的真实工作建立一套空间语言。

A

一眼看懂状态

在想、在执行、在等待还是失败，不需要翻完整时间线。

B

动作有空间含义

读文件去档案柜，跑命令去服务器，委派任务去会议桌。

C

协作真正可见

每个 subagent 都是一名进入办公室、接活、工作并交付的同事。

02 / UNDER THE HOOD

真实事件，
变成办公室里的动作。

插件监听 Pi 已经开放的会话事件，只做本地翻译与渲染，不改变 Agent 的工作方式。

LOCAL ONLY 代码与会话数据不会上传到云端
message_update思考气泡
read / grep档案柜
bash / exec服务器区
subagent会议桌
agent_settled返回工位
