LAYOUT IDEA 03

Boardroom as Office

不是偶尔开会，而是直接把大会议室变成工作现场。Agent 固定坐在长桌两侧，主 Agent 或老板位于桌首，随时讲话、分派与总结。

工作映射

Head Seat计划 / 分派 / 最终决策
Team Seats编码 / 调研 / 写作 / 测试
Main Screen任务状态 / Diff / 结果展示
Hot Seat汇报 / 提问 / 等待审批
Service Edge茶水 / 文件 / 设备支持

空间特征

  • 一张占据视觉中心的超长木质会议桌。
  • 老板在桌首和大屏之间讲话，方向关系明确。
  • 每个座位都有电脑、文件、杯子和桌面身份牌。
  • 会议电话、投影控制台、白板、茶水车和秘书 NPC。
